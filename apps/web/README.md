# ActoCore Web

Marketing site built with **Vite + React + React Router + react-i18next**.

## Scripts

- `npm run dev` — dev server on port 3001
- `npm run build` — production build to `dist/`
- `npm run preview` — preview production build

## Environment

Copy `.env.example` to `.env`:

- `VITE_SITE_URL` — public site URL
- `VITE_STUDIO_URL` — Studio app URL for CTAs

## Locales

Routes are prefixed with locale: `/en`, `/fr`, etc. Translation files live in `src/i18n/locales/`.
